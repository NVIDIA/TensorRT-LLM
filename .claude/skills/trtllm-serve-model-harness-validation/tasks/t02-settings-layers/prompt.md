This workspace has a settings loader, loader.py, and layered settings files under settings/. Read loader.py to learn which layers it applies, in what order, and how each kind of line changes the result. Then read the layer files, all of them in one step where your tools allow it; the loader skips a layer whose file does not exist, so if a read fails, note it and go on. Work out the effective settings of the [server] and [cache] sections once every layer has been applied, without running any code, and answer with one line per key in the form section.key = value. If your harness can start sub-agents, you may hand the reading of the layer files to one; otherwise do everything yourself. Do not modify any files.
