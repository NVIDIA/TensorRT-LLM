Run `python3 make_data.py` first; it writes station.log, a service log of 3,000 lines. Then read station.log from the first line to the last, 200 lines per read, with your file-reading tool (or `sed -n` if you only have a shell). Do not grep, count, sort or parse it with a script or a one-liner: the point of this task is to read it. Keep your notes in findings.md: after each part, and before you read the next one, append every WARN and ERROR line of that part (time, node, level and message) and update the file's first line to say how many lines you have read so far. If your context gets compacted, carry on from findings.md rather than from memory. When you have read the last line, answer from findings.md: how many WARN lines and how many ERROR lines the log has, which node logged the most of them, and the sum of the dropped= values over all ERROR lines.
